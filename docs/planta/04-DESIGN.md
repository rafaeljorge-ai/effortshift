# Direção visual

Decisão reversível do executor autorizada pelo usuário: instrumento de controle local, escuro e calmo, sem marca Mavik. Domínio: esforço, marcha, sinal, sessão, orçamento, contexto. Cores do instrumento: grafite #101214, superfície #191c20, texto #edf0ed, secundário #b0b7b0, sinal menta #a6e5bc, aviso âmbar #edbe77, falha coral #ef9292. Sem gráficos de uso fictícios.

Assinatura: faixa de cinco níveis de esforço, nível selecionado iluminado, com estado recomendado/enviado/aceito legível e motivo logo abaixo. Tipografia: fontes locais system-ui e ui-monospace para valores/terminal. Escala 12/14/16/20/28. Base de espaçamento 4px. Bordas discretas, foco visível, hit areas 44px.

Espécime:
```
EFFORTSHIFT                         LOCAL / Codex conectado
Sua sessão, na marcha certa.
[low] [MEDIUM] [high] [xhigh] [max]     AUTO
Implementação: esforço medium — aceito pelo servidor
------------------------------------------------------
Conversa real                         CONTROLES
                                      Perfil Equilibrado
[ Escreva uma tarefa...          ]     Modelo do catálogo
[ Enviar tarefa ] [ Interromper ]      Eventos da sessão
```

Mobile 390px: uma coluna, compositor acessível, sem overflow horizontal. prefers-reduced-motion; sem animações contínuas. Sem fontes externas. Renderizar saída como texto, nunca HTML do agente.
